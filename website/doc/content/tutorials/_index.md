Lessons that take you from nothing to a result on screen. Each one states what you need and how long it takes, and explains only what the next step requires. Start with the first city; the others assume you have it.

If you already know what you want to do, the [how-to guides](/how-to/) answer one question each; if you want to know why something is the way it is, read the [explanations](/explanation/).
